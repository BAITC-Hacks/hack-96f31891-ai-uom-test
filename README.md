# FAQ-бот на 5 вопросов

Небольшой терминальный бот для репетиции HackAlem AI. Он отвечает на пять заранее известных вопросов: о времени репетиции, команде, треке, сдаче и призах. Данные лежат в [`faq.txt`](faq.txt) и основаны на регламенте репетиции: это не основной HackAlem AI, призового фонда нет, а сдаётся репозиторий команды до 22 сентября 2026 года, 20:00 (UTC+5).

## Запуск

Нужен только Python 3 — внешние библиотеки не используются.

```bash
python3 main.py
```

Пример:

```text
Вы: Когда дедлайн сдачи?
Бот: До 22 сентября 20:00 нужно сдать репозиторий команды...
Вы: выход
Бот: До встречи!
```

Бот переводит вопрос в набор слов и считает совпадения с ключевыми словами у каждой записи из `faq.txt`. Он печатает ответ из наиболее похожей записи. Если совпадений нет, отвечает «Не знаю».
